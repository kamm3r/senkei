# Matrices

Build and invert column-major 4x4 transforms

---

## Construct by parts

The constructor takes four Vec4 columns. Element names follow m{row}{col}, so the first digit is the row and the second is the column — translation lives in column 3.

```ts
const m = new Mat4(
  new Vec4(1, 0, 0, 0),
  new Vec4(0, 1, 0, 0),
  new Vec4(0, 0, 1, 0),
  new Vec4(0, 0, 0, 1)
)
```

identity and zero getters cover the boring cases. TRS() fuses translation, rotation, and scale into a single allocation — a seeded differential fuzz test verifies it against the explicit product.

```ts
const trs = Mat4.TRS(pos, rot, scale)
const view = Mat4.LookAt(eye, target, Vec3.up)
const proj = Mat4.Perspective(60 * Mathf.Deg2Rad, 16 / 9, 0.1, 100)
```

Translate(), Rotate(), and Scale() build the individual pieces, and Perspective(), Ortho(), and Frustum() produce projection matrices.

---

## Transform points and vectors

Multiply handles matrix-by-matrix and matrix-by-Vec4. For 3D work the instance methods are more direct. MultiplyPoint() does a full perspective divide, MultiplyPoint3x4() skips it for affine matrices, and MultiplyVector() ignores translation entirely.

```ts
const point = m.MultiplyPoint(worldPoint)
const affine = m.MultiplyPoint3x4(worldPoint)
const dir = m.MultiplyVector(direction)
```

---

## Read the parts back

GetPosition() pulls the translation column. GetColumn() and GetRow() copy any line out, while SetColumn() and SetRow() write one back — all of them throw on an out-of-range index. The transpose, determinant, and rotation getters decompose the matrix without touching it.

```ts
const pos = m.GetPosition()
const col = m.GetColumn(2)
const det = m.determinant
const rot = m.rotation
```

SetTRS() rebuilds the whole matrix in place, and clone() duplicates it.

---

## Deal with singular inversion

inverse is a documented failure point: a zero or non-finite determinant means no inverse exists, and the library throws rather than hand back a matrix full of NaNs.

```ts
try {
  const inv = m.inverse
} catch {
  // singular matrix: nothing to invert
}
```

Check for zero before trusting a bottom-heavy matrix.
