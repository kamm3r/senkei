# Getting started

Install, import, and animate your first object

---

## Install

```bash
npm install senkei
```

Imports come from the package root.

```ts
import { Vec3, Quaternion, Mat4, Transform, Mathf, Space } from 'senkei'
```

---

## Try it

Static methods return fresh objects, so your inputs stay untouched.

```ts
const point = new Vec3(2, 4, 10)
const sum = Vec3.Add(point, new Vec3(34, 3, 2))

const t = new Transform()
t.position = new Vec3(0, 1, 0)
t.LookAt(new Vec3(0, 1, 5))
console.log(t.forward)
```
